# MQ3 compact player

Use this update instead of the uninstalled Player Design Polish ZIP. Upload the public folder contents to GitHub preserving public/app.js and public/styles.css. Commit, wait for Vercel Ready, then refresh. No SQL or environment changes.

The player exposes a compact title/play/timeline strip with a thin champagne-gold edge, rounded corners and subtle shadow. No added MQ3 logo, badge or wordmark. The provider artwork and footer are outside the visible strip. Existing gift eligibility, Share, Close and Lyrics controls remain. Previous iframe navigation restrictions remain.

Validated with the actual public Moses embed: title/control positions at desktop and 390/320px mobile widths, playback, seeking, pause/resume, blocked outbound link navigation and iframe removal on Close. Check your actual phone after deployment. This layout depends on Suno's current player geometry and may require adjustment if the provider changes it.

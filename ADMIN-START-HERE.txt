IMPORTANT SCOPE
This is an update for the existing configured app, not a new database
installer. The migration requires the existing song_creator_requests table.
If your live code differs from mq3music-main (2).zip, compare before replacing
files so newer changes are not overwritten. Do not combine this with the
unfinished checkpoint files.

Email acceptance is not proof of inbox delivery. SMTP does not guarantee
exactly-once sending: if a server stops after SMTP acceptance but before
recording success, manual retry can send a second notification. Older
Not tracked requests may already have been emailed; the UI asks before
sending those again. Retry is manual, not an automatic background job.
